# Personal Budget Tracker (Visual Design Enhancement)

This project is a polished, user-friendly **Personal Budget Tracker** web application designed to help users track and organize their daily expenses. This week's focus centers entirely on enhancing the visual presentation using modern CSS techniques without altering the underlying HTML structure or functionality.

---

## What Was Built

The application features a clean, professional interface divided into three distinct visual sections ("cards"):
1. **Header Section:** Introduces the app with a cohesive title and subtitle.
2. **Add Expense Form:** A cleanly padded input form equipped with styled form elements and a primary accent action button.
3. **Expense History Table:** A structured data table featuring custom header styling, alternating row colors (zebra striping), and responsive padding.

---

## Key Features & Design Choices

* **Intentional Color Palette:** Built around a cohesive deep teal primary theme (`#0f766e`) combined with soft neutrals (`#f4f6f8` background and `#1f2937` typography) for a trustworthy, professional financial app aesthetic.
* **Custom Typography:** Integrated Google Fonts (**Poppins** for strong, modern headings and **Inter** for clean, readable body text) to build a clear visual hierarchy.
* **Table & Form Styling:** Features rounded input borders, interactive focus rings, structured cell padding, and alternating row backgrounds for high readability.
* **CSS Box Model Implementation:** Employed margins to separate major layout sections, padding for breathing room inside containers, and border-radius properties to give the entire interface a soft, modern card layout.
